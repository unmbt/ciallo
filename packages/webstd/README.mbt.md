# unmbt/webstd

Zero-dependency WinterTC (ECMA-429) Web Standards primitives (`Url`, `Method`, `status_reason`, `Headers`, structured `Cookie`, `Body`, `ByteStream`, `Request`, `Response`, `SseDecoder`, `NdjsonDecoder`) supporting `native`, `js`, `wasm`, and `wasm-gc`.

See [SKILL.md](SKILL.md) and the workspace documentation in `../../docs/`.
